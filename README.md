# JumpGuru

Android-приложение для измерения вертикальных прыжков с WT9011DCL BLE 5.0.
Цели — проверяемая точность и удобный современный интерфейс. Точность остаётся
первым приоритетом. Статус: подготовлена инфраструктура; APK и алгоритма ещё нет.

Датчик у владельца есть, телефон — Samsung Galaxy S26+. Встроенной памяти в датчике
нет (подтверждено владельцем): телефон рядом с площадкой непрерывно записывает Bluetooth-поток.
Разрыв связи означает потерю данных, которую нельзя скрывать или восстанавливать догадками.

## С чего начинаем

1. **Проверяем железо.** Версия Android/прошивки датчика, крепление, протокол,
   фактическая частота и устойчивость связи в зале.
2. **Делаем APK-регистратор.** Подключение, старт/стоп, сырые пакеты, журнал потерь,
   запись с выключенным экраном и экспорт. Это первый полезный результат для владельца.
3. **Собираем эталонные записи.** Прыжки и движения без прыжков с синхронным видео;
   для строгой проверки высоты — силовая платформа или подходящая система motion capture.
4. **Сравниваем алгоритмы.** Разделяем обнаружение прыжка и оценку высоты,
   проверяем на людях/сессиях, не использованных при настройке.
5. **Собираем MVP.** Выбор активности, запись тренировки, количество, высоты,
   максимум/среднее только по пригодным измерениям, история и качество записи.
6. **Позже изучаем типы прыжков.** Блок/атака/подача требуют размеченных спортивных
   данных; возможность различать их одним датчиком пока не подтверждена.

## Решения

- Нативный **Kotlin + Jetpack Compose + Material 3**, Coroutines/Flow, Room.
- Автономная работа приложения без интернета; Bluetooth к датчику обязателен.
- Чистое Kotlin/JVM-ядро измерений, независимое от Android и BLE.
- Python только для исследовательских инструментов и отчётов; итоговый алгоритм — Kotlin.
- **Docker сейчас не нужен.** Сервер отсутствует; контейнер не заменяет телефон и BLE.
- Код, тесты, сборки и ревью делают агенты. Владелец определяет продукт и проводит
  физические записи по короткой инструкции. Ручное редактирование кода не требуется.

## Проверка инфраструктуры

```bash
python3 scripts/check.py
python3 scripts/doctor.py
```

Первая команда проверяет инфраструктуру репозитория, не Android-приложение и не точность.
Вторая сообщает о недостающем Android toolchain. Сборка APK появится в JG-001.
