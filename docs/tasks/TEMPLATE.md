# JG-NNN — название

- Статус: proposed
- Владелец: назначает координатор
- Base SHA: фиксируется при старте
- Worktree / branch: фиксируется при старте

## Результат для пользователя

Описать наблюдаемое поведение.

## Область и зависимости

Указать разрешённые пути, владельца контрактов и то, что блокирует задачу.

## Критерии приёмки

Перечислить наблюдаемые результаты, включая ошибки/восстановление.

## Проверка

Указать команды, fixtures, потребность в устройстве и единственного владельца запуска.

## Отчёт / handoff

SHA, изменения, выполненные и пропущенные проверки, findings reviewer, оставшиеся риски.
