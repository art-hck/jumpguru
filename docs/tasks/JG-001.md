# JG-001 — воспроизводимый Android-каркас

- Актуальные статус, исполнитель, base SHA и worktree: [Issue #3](https://github.com/art-hck/jumpguru/issues/3).
- Этот файл — спецификация, не журнал выполнения.

## Результат

Собираемый debug APK JumpGuru с минимальным экраном состояния. Это основа для
регистратора, без фиктивного Bluetooth-подключения и без демонстрационных высот.

## Область

Gradle wrapper/build-logic/version catalog, модули из docs/architecture.md,
app manifest и минимальный Compose экран, Android CI и обновление docs/development.md.
Один агент владеет всеми общими build-файлами. Не реализовывать алгоритм прыжков,
спортивную классификацию, облако, Bluetooth-протокол или интерфейс всей тренировки.

## Критерии

- Проверены совместимые stable JDK/AGP/Gradle/Kotlin/SDK; версии и checksum зафиксированы.
- APK собирается с чистого checkout документированной командой.
- Measurement-модуль не зависит от Android.
- Настроены backup/data-extraction rules: будущие raw-записи, база и диагностические
  экспорты исключены из автоматического cloud backup/device transfer.
- Работают релевантные unit/lint/build проверки, без тестов ради покрытия строк.
- CI действительно собирает Android и сохраняет debug APK; bootstrap остаётся отдельной проверкой.
- Пользователю выдана инструкция установки APK; запуск на S26+ помечен pending,
  пока владелец/подключённое устройство не подтвердит его. Emulator не доказывает BLE.
- Независимые reviewer и tester проверили один кандидатный SHA.
