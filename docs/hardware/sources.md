Для повторного получения PDF: `https://drive.google.com/uc?export=download&id=FILE_ID`,
где FILE_ID взят из соответствующей ссылки. После загрузки сравнить SHA-256;
изменившийся документ — новый источник, требующий просмотра diff выводов.
PDF и SDK не включены в репозиторий; сохраняются собственные выводы и ссылки.
Отдельного файла LICENSE в скачанном S7 не найдено; разрешение на включение SDK/кода
в приложение не установлено. Наличие публичного GitHub не заменяет лицензию.

## Идентификация товара

[Ozon SKU 1906602111](https://www.ozon.ru/product/witmotion-akselerometr-datchik-dvizheniya-chernyy-matovyy-goluboy-1906602111/)
проверен первым через Ozon MCP: `OZON_ACCESS_BLOCKED`, HTTP 403.
Использован fallback к первичным материалам WitMotion. Название WT9011DCL BLE 5.0
унаследовано из документации проекта от 2026-09-19, где отмечено прежнее чтение Ozon.
Сейчас карточка повторно не подтверждена; из slug ничего не выведено.
Соответствие конкретного товара/экземпляра этим PDF устанавливается по маркировке,
версии и capture, а не по цвету корпуса или имени BLE.

## Расхождения, которые нельзя замалчивать

| Тема | Наблюдение | Решение для JumpGuru |
|---|---|---|
| Батарея | S4 с.5–6: 130 mAh, 8 ч, зарядка 2 ч; S2: 100 mAh, 24/30/40 ч в разных местах | Не обещать время работы; измерить в выбранном режиме |
| Габариты | S4 с.6: высота 11.4 мм; с.8: 11.6 мм | Для крепления обмерить экземпляр; ориентир 32.5 × 23.5 × 11.6 мм, 9 г |
| Точность/магнитометр | S4 с.6–7 содержит разные диапазоны магнитометра и точности углов | Не выбирать наиболее выгодное значение; магнитный масштаб остаётся неподтверждённым |
| Магнитные данные | S4 с.16: raw в mG; S5 с.8: raw/150 в µT; S7: raw/120 без достаточного объяснения единиц | Хранить raw; SI-магнитометр не включать до проверки ревизии |
| Фильтр 0x1F | S5 с.12–13: 188 Гц → 0x01, 20 Гц → 0x04; Java S7: 188 → 0x02, 20 → 0x05 | Не переносить таблицу SDK автоматически; проверить readback и отклик |
| Unlock | S5 с.10: `FF AA 69 88 B5`; с.11–12: `FF AA 68 B5 88` | Не перебирать команды на устройстве; выбрать подтверждённую последовательность для его прошивки |
| Минимальная частота | S4: код 0x01 = 0.2 Гц; S5: 0.1 Гц | Для пилота важны 100/200 Гц, но весь профиль версионировать |
| Версия прошивки | Разные формулы в S4 с.18 и S5 с.9–10 | Сохранять сырые 0x2E/0x2F и строку приложения, не угадывать формат |
| Checksum | S4 с.16–17 и S5 с.9 вставляют формулу для `55 59`, хотя описывают `55 71` | Не добавлять UART checksum в 20-байтовый BLE пакет |
| Калибровка компаса | S1/S3 рекомендуют; FAQ S2 обычно не рекомендует повторять заводскую | Сначала baseline, затем отдельный обоснованный эксперимент, не перед каждой записью |
| Режим 0x96 | S5 добавляет перемещение/скорость с тем же `55 61`; старые SDK декодируют всегда как IMU | Явно подтверждать режим и прошивку; неизвестный режим → только raw |

S2 также упоминает GPS/давление и «data logging» в общих рекламных блоках.
Это не доказательство GPS, барометра или встроенной записи у нашего датчика.
S3 с.36 прямо говорит об отсутствии памяти, а с.35 ограничивает reset height
другими моделями с барометром. Дата нового PDF сама по себе не доказывает, что
старый экземпляр поддерживает все новые регистры.
