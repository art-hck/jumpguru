# Среда разработки

На момент bootstrap в этой среде есть Python 3.12 и Git; Java, Gradle, adb и sdkmanager
в PATH не найдены. Android APK пока не собирался. Агент JG-001 ставит/настраивает
совместимый toolchain, фиксирует версии и проверяет сборку; владелец код не настраивает.

## Сейчас

```bash
python3 scripts/check.py
python3 scripts/doctor.py
git diff --check
```

`check.py` требует Python ≥ 3.11, без внешних пакетов. Проверяет обязательные файлы,
TOML ролей, локальные навыки и целостность зафиксированных сторонних файлов.
`doctor.py` — диагностика, exit 1 означает недостающие инструменты Android.
Наличие утилит не подтверждает их совместимость и работоспособность Bluetooth.

## JG-001 должен добавить

1. JDK и Android SDK с документированными версиями; Gradle wrapper с distributionSha256Sum.
2. version catalog, dependency verification/locking там, где поддержано, lint/format policy.
3. Один путь сборки для локальной машины и CI. Команды unit, lint, assembleDebug
   указать после реального появления задач, не добавлять фиктивно зелёные заглушки.
4. CI с debug APK как артефактом, без signing secrets для debug. Для release позднее —
   отдельный защищённый signing workflow; ключи в Git никогда не хранятся.
5. Доставку APK и простую инструкцию владельцу, сбор диагностического экспорта.

## GitHub

Workflow `.github/workflows/bootstrap.yml` уже подготовлен; удалённо пока не выполнялся.
Когда владелец создаст GitHub-репозиторий и поручит подключение, агент добавит remote,
запушит main и проверит CI. Затем настроит запрет force-push и required checks на main
с учётом доступных прав/тарифа. Эти настройки не применяются локальным YAML автоматически.
Не требовать ручного код-ревью от владельца: независимые агенты дают техническое ревью,
владелец принимает продуктовые решения. Кто может технически merge, определяется правами GitHub.

GitHub Actions закреплены по SHA. Dependabot отключён по решению владельца;
обновления зависимостей и actions выполняют агенты отдельными задачами.
Не использовать pull_request_target для исполнения кода внешнего PR.
CI не получает реальные данные тренировок. Локальная папка local-data/ игнорируется.
