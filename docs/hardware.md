## Что известно

Датчик есть у владельца; телефон — Samsung Galaxy S26+, версия Android пока неизвестна.
Рабочая идентификация — WT9011DCL / WT9011DCL-BT50 / WT9011DCL-BT5.0 из документации
проекта. Это не подтверждение ревизии конкретного экземпляра. Ozon SKU 1906602111
повторно прочитать не удалось (403); исследованы первичные материалы производителя.
Полная трассировка — в [реестре источников](hardware/sources.md).

| Параметр | Заявление производителя, не результат наших испытаний |
|---|---|
| Тип | IMU/AHRS: акселерометр, гироскоп, магнитометр; углы вычисляются встроенным алгоритмом |
| Связь | BLE 5.0; Type-C. USB/CH340 описан в руководстве, доступность на экземпляре проверить |
| Акселерометр | ±16 g; 16-битное кодирование, шаг 16/32768 g ≈ 0.000488 g |
| Гироскоп | ±2000 °/с; шаг 2000/32768 ≈ 0.061 °/с |
| Углы | Roll/Yaw ±180°, Pitch ±90°; у Эйлера особая точка при Pitch ±90° |
| Угловая точность | S1: 0.2° roll/pitch, 1° heading без магнитных помех; в S4 есть расхождения |
| Поток | Ускорение + угловая скорость + углы по умолчанию; магнитометр/кватернион читаются отдельно |
| Частота выдачи | По S1/S4 до 200 Гц, default 10 Гц; это не доказательство 200 независимых измерений/с |
| Полоса фильтра | В материалах 5–256 Гц, default 20 Гц; команды различаются между источниками |
| Память записи | Отсутствует: подтверждение владельца и S3 с.36; пишет телефон, потери невосстановимы |
| Питание | S4: 3.3–5 В, Type-C; S3 предупреждает не подавать более 5 В |
| Корпус | Ориентир 32.5 × 23.5 × 11.6 мм, 9 г; крепление проверяется по экземпляру |
| Дальность/батарея | Заявления различаются; рабочие значения определяются испытаниями в зале |

Источники таблицы: S1, S3 с.6/22–24/36/41–43, S4 с.5–10/12–16,
S5 с.3–9; ссылки и SHA в реестре. Разрешение кодирования не равно точности.
Температурные пределы электроники не означают допустимость зарядки во всём диапазоне.
В изученных материалах не установлена пригодность корпуса к поту/воде/ударам при игре;
не считать его водонепроницаемым и не переносить рекламную ударостойкость на крепление.

## Что это означает для измерения прыжков

Это источник инерциальных данных, не готовый измеритель высоты центра масс.
Даже новый режим перемещения из S5 не прошёл спортивную валидацию и не заменяет
[наш измерительный протокол](measurement.md). Угловая точность не переводится в сантиметры.

- Акселерометр измеряет удельную силу в осях корпуса: в покое ожидается норма около
  1 g, а не ноль. Проверить знаки в шести положениях. Для мировой системы с Z вверх:
  `a_world = R_body_to_world * f_body + (0, 0, -g)` после подтверждения конвенции.
  Вычитать g непосредственно из произвольной оси корпуса нельзя.
- Предварительное крепление — плотный пояс у крестца/поясницы. Датчик не должен
  болтаться; фиксировать сторону корпуса и ориентацию. Его движение не тождественно
  движению общего центра масс. Новое место крепления — отдельные условия валидации.
- Штатные углы и кватернион уже прошли fusion/фильтрацию. Их задержка и поведение
  при ускорении неизвестны. 200 BLE пакетов/с не доказывают полосу 100 Гц или
  синхронность всех каналов. Запрашиваемый кватернион нельзя считать одновременным с IMU.
- Настройки фильтра влияют на шум, задержку и форму отрыва/приземления. Повторные
  значения сохранять: они могут возникать из-за квантования, фильтра или обновления
  каналов; ни удаление повторов, ни их подсчёт не дают частоту физических измерений.
- Удар при приземлении может насыщать ±16 g. Отмечать clipping и исключать расчёт
  через непригодный участок, не превращать насыщенные значения в достоверную высоту.
- 9-axis fusion чувствителен к металлу и магнитам; 6-axis допускает дрейф heading.
  Выбор режима требует сравнения, а не автоматического переключения во время записи.
- В 20-байтовом основном кадре нет timestamp/sequence. Время BLE callback — время
  приёма. Точный процент потерь samples без дополнительного подтверждения неизвестен.

Это инженерные следствия формата/принципа IMU; точность на человеке пока не измерялась.

## Использование и калибровка

Сначала снять baseline без изменения настроек. Записать версию, режим, текущую частоту,
полосу, монтаж и историю калибровки; неизвестное хранить как unknown. Приложение
производителя и наш регистратор использовать по очереди, освобождая подключение.
Имя вида WT901BLE не идентифицирует модель однозначно.

S3 с.11/31–32 описывает калибровку акселерометра на неподвижной горизонтальной
поверхности с проверкой Z≈1 g. Не выполнять её на надетом поясе; проверка шести
положений — отдельный диагностический тест, не автоматическая шестипозиционная
запись новых коэффициентов. Изменения калибровки сохранять как новую версию.

Калибровку магнитометра и изменение 6/9-axis выполнять отдельным экспериментом после
baseline, с фиксацией до/после. Металлическая стойка, магнитный ремешок и электроника
рядом могут менять поле; даже соблюдение указанного в S4 расстояния 20 см не гарантирует
отсутствия помех. Не обнулять углы, не сбрасывать настройки и не калибровать посреди сессии.
Прошивку не обновлять без отдельной задачи.

Для прыжков использовать заряженный датчик без подключённого зарядного кабеля.
Перед длительной записью проверить запас батареи в рабочем режиме. Процент по
напряжению из SDK — оценка, не обещание оставшихся минут. Телефон размещать так,
чтобы связь сохранялась при поворотах и экранировании телом; дальность на открытом
пространстве не является критерием приёмки в зале.
