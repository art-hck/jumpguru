# Установленные навыки

Навыки включены в Git в `.agents/skills/`, поэтому доступны следующим агентам вместе
с checkout. Автообнаружение Codex ожидается со следующего хода/новой сессии;
в текущем сеансе их можно прочитать по пути. Глобальные настройки не менялись.

| Навык | Происхождение | Когда нужен |
|---|---|---|
| testing-setup | Google, android/skills | Настройка Android unit/UI/instrumented проверок |
| navigation-3 | Google, android/skills | Навигация и сохранение состояния Compose |
| adaptive | Google, android/skills | Размеры окна, масштаб текста, адаптивная компоновка |
| edge-to-edge | Google, android/skills | Системные панели, вырезы, клавиатура и доступность кнопок |
| jumpguru-ui-ux | Создан для проекта | Визуальная система, сценарии тренировки, доступность и приёмка UI |
| jumpguru-android-ble | Создан для проекта | Непрерывная запись, протокол, reconnect, потери |
| jumpguru-measurement | Создан для проекта | Валидация алгоритмов, timing, метрики и эталон |
| jumpguru-delivery | Создан для проекта | Изолированные задачи, reviewer/tester, проверяемая сдача |

Официальные навыки скачаны из [android/skills](https://github.com/android/skills)
на commit `b1f707d90904129b5972b3cc6436b568583effe5`, Apache-2.0.
Источник выбран за официальное происхождение и релевантность; популярность не заменяет
проверку содержимого. Сохранены справочные файлы и LICENSE.txt. Содержимое upstream
не изменено. `skills-lock.json` фиксирует SHA-256 каждого установленного файла.

Это инструкции агентам, не Android-библиотеки. Их установка не добавляет Hilt,
тестовые frameworks или Gradle. Широкий testing-setup использовать в пределах
текущей задачи; сейчас реализации приложения ещё нет. Не устанавливать все
предлагаемые screenshot/E2E-инструменты заранее.

Проверка: `python3 scripts/check.py`. Обновление навыка — отдельная задача с чтением
diff, сохранением лицензии/атрибуции, обновлением upstream commit и file hashes.
Собственные навыки не являются валидированными алгоритмами измерения.

## Выбор UI-навыков (2026-09-19)

Проверены содержимое и происхождение навыков. В каталоге
[adaptive](https://www.skills.sh/android/skills/adaptive) — около 1.7K установок,
[edge-to-edge](https://www.skills.sh/android/skills/edge-to-edge) — около 2.3K;
официальный репозиторий android/skills — около 7.4K звёзд на момент проверки.
Это показатели распространения, не доказательство качества.

`adaptive` содержит также экспериментальные API и широкие миграционные рекомендации.
Они не являются разрешением менять выбранный stable-стек или расширять MVP до TV/XR.
`styles` не установлен: он ориентирован на отдельный Compose Styles API и требует
alpha-зависимость, не нужную для текущей задачи.

Доступный в среде `ui-ux-pro-max` изучен и опробован для спортивного приложения.
Его подборка выдала также landing-page/hover/CSS рекомендации, поэтому автоматически
не перенесена в native Android. Этот глобальный навык не скопирован в репозиторий.
Проектный `jumpguru-ui-ux` самодостаточен и не требует его установки.
